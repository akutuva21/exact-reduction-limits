# ELI15: what this paper proves, and what Lean is checking

## The short version

A rule-based biochemical model can be written using only tiny local rules and
still need global or infinite state to predict an assay exactly.

That sounds paradoxical only if you confuse **how a system updates** with **what
information is sufficient to predict it**.

A chess move is local: move one piece.  But predicting the game requires the
whole board.  The paper gives exact stochastic analogues of that idea for
Kappa/BNGL.

## 1. The scanner example

Imagine a motor sitting somewhere inside a long, perfectly repetitive chain.  It
moves one unit at a time until it hits the marked end.  The assay says only
`Done` or `NotDone`.

Every chemical rule is local: look at the motor and its neighboring unit, then
move one step.  But if the chain is homogeneous, two positions deep in the
interior look identical to any fixed collection of bounded local patterns.

One motor might have 20 steps left; another might have 200.  Their local
neighborhoods can be identical, but their completion-time distributions are not.

The exact missing state is simple:

```text
distance remaining
```

It is only one integer.  The problem is not high dimension.  The problem is
**nonlocality**.

Lean represents a local observable by a finite inspection radius and proves that
two carefully chosen deep positions on the same chain have identical values for
every observable in an arbitrary finite family.  It then proves that their
Erlang survival probabilities differ.

## 2. Why the original scanner seed is easier

Now start from the particular seed used to construct the scanner.  The chain
grows for a random amount of time, then freezes, then the motor scans to the
end.

Surprisingly, after averaging over that random construction history, the Done
time collapses to a two-phase distribution.  Add the absorbing Done state and
you get an exact three-state hidden CTMC.

So these are different questions:

```text
Can one finite state description work after every possible restart?
```

versus

```text
Can the assay from this one chosen initial preparation be generated by
some finite hidden CTMC?
```

The scanner says **no** to the first and **yes** to the second.

Lean proves the recurrence algebra and the exact factorization into two positive
phase rates.

## 3. The reversible-tip example flips the answer

Take a polymer with one unique reactive tip.  The tip can grow by one unit at
rate `λ` or shrink by one unit at rate `μ`, with `μ > λ`.

The exact mechanistic state is again tiny:

```text
active length = 0,1,2,3,...
```

That is one integer, so the coordinate dimension is one.  But there are
infinitely many possible values.

The time until the length hits zero has the classical M/M/1 busy-period
transform

\[
\rho(s)=\frac{s+\lambda+\mu-
\sqrt{(s+\lambda+\mu)^2-4\lambda\mu}}{2\lambda}.
\]

The square root makes the exact transform non-rational.  Any finite-dimensional
time-homogeneous linear system, including any finite hidden CTMC, has a rational
Laplace transform.  Therefore no finite hidden CTMC can reproduce this assay
exactly from the seed.

Lean proves the quadratic/root algebra and the contradiction logic.  The
classical queueing theorem that this is the M/M/1 busy period and the classical
non-rationality/matrix-exponential theorems are explicit background interfaces.

## 4. Approximation is still allowed

None of this says finite models are useless.

Finite phase-type models can approximate the reversible-tip law arbitrarily
well.  The exact statement is subtler: if you demand closer and closer
convergence to the true infinite-state law, the number of phases cannot stay
bounded.

So "I can fit it with 8 states" is not the same claim as "the true mechanism has
an exact 8-state representation."

## 5. There is a positive boundary

Suppose every connected molecular complex is guaranteed to contain at most `B`
agents.  With a finite molecular signature, only finitely many fully specified
connected species can then occur.

Count how many copies of each species are present.  That finite vector determines
the entire mixture exactly.

Lean proves the key injectivity statement: two finite multisets with identical
counts for every species are the same mixture.

Copy numbers can still be arbitrarily large, so the state space can remain
infinite even though the coordinate vector has finite dimension.

## 6. Why no perfect checker can exist

A Kappa free-site test can answer an exact zero question:

```text
is this root site free?
```

Represent a counter as a chain attached to a root.  Empty chain = zero.  Add one
node = increment.  Remove one node = decrement.  Test whether the root is free =
zero test.

With two such counters and a finite controller, you can simulate a deterministic
two-counter machine.  Halting for the relevant machine class is undecidable.

Lean formalizes the numeric counter semantics and proves that the zero/nonzero
and one/many cases are mutually exclusive, so exactly one local rule variant is
enabled.  The full site-graph syntax compiler and the external CM2 halting
undecidability theorem are explicit interfaces.

The paper then wires halting into two different assay constructions:

- for the **one-seed hidden-state** question, nonhalting produces a detector law
  with infinitely many Laplace poles, while halting switches to the scanner seed;
- for the **reusable local-state** question, nonhalting exposes arbitrarily long
  frozen scanners, while halting switches to the reversible tip.

A generic Lean theorem then transfers undecidability through either compiler.

## 7. Why omega refinement appears

Start by grouping scanner states only by the current assay: Done versus NotDone.
Then repeatedly split states according to their rates into the current groups.

After one round you discover distance 1.  After two rounds you discover distance
2.  After `n` rounds you have discovered exactly distances `0,...,n`; every
larger distance is still merged into one tail.

No finite number of rounds finishes the job.

Lean proves this closed form and proves that equality at **every** finite depth
forces the true distances to be equal.  That is the concrete scanner witness for
why the coarsest strong lumping appears only at the `ω` intersection.

## 8. What Lean adds

Lean is useful here because the paper contains several distinctions that are
easy to blur in prose:

```text
finite rule text
finite coordinate dimension
finite local expressibility
finite state cardinality
one-seed finite hidden realization
reusable exact Markov state
```

They are not equivalent.

The repository makes those quantifiers and implications explicit.  It also
makes the trust boundary explicit: paper-specific arguments are Lean proofs;
large classical theorems reused from queueing, probability, and computability
are typed inputs until separately formalized.
